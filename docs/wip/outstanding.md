## 2 · Windows：一直挂着

- **这台机器验不了。** 没有 Windows 宿主，也没有它的模拟器（`wine` 不存在，
  Docker for Mac 跑不了 Windows 容器）。
- 已有的是**一个 cmd.exe 批处理子集解释器**，跑过 8 条 `commandWindows` 的双向
  检查（脚本不在 → 先退 0 且不碰解释器；脚本在 → 到得了 `where`/`py`）。
  **它证明守卫的逻辑，不证明 Windows。** 收据里就是这么标的。
- **共享文件的 Windows 分支只认 `%CLAUDE_PLUGIN_ROOT%`**，而同一文件的 POSIX
  分支会回落到 `ZCODE_PLUGIN_ROOT` 并顺带带上 `--host zcode` —— 就是 F2 那条
  「路径和宿主标签取自同一个变量」。所以 **Windows 上的 zCode 会在字面路径上过不了
  守卫、静默退 0**：fail-safe，但门根本不跑。cmd 里写这个回落要 `if defined` +
  延迟展开，**这台机器连一次都执行不了**，而拿没法执行的批处理去关一条 finding，
  正是 `python3 X || python X` 那次的成因。**它就挂在这儿。**
- `commandWindows` 只有 **Codex** 的 reference 写了；CC 的 Windows 旋钮是
  `shell: "powershell"`，zCode 的是 `process`（argv，不过 shell）。共享文件里那
  四处是**实测无害的装饰**（两家都照常加载，zCode 直接对拍过），真正承重只在
  `hooks/codex.json`。
