## 仍需独立运行验收的范围

1. **真实业务收口**：原 2.14 正式试验已有正确业务产物及真实独立 review，但 Claude 账户会话限额阻断最终 verify；同 session 恢复一次仍被拒绝，`closure_pass=false`。该试验已按原协议结束，不能重写旧失败或补造 Stop。若以后验收保留现场，应新记条件和结果。
2. **启动与完整自主链路**：前向目标生成样本在真实模型上下文中执行过独立规格质询，生成的 Anchor 经父评测的正确/错误样本检查。但场景仅生成目标包，没有启动业务；它不能代替“未经质询的已批准制品收到 start-now”的启动试验，也不能代替原生续跑 → 业务 → review → verify → 原生收口。
3. **平台覆盖**：本次没有重做四家原生插件安装/发现或 Windows 原生锁/生命周期。SIGKILL、模板、清单和 Hook 契约检查不能替代这些验收。进程中断也不等同断电持久性。
4. **组合可靠性**：任意多模型并发、所有 UI 强制取消/中断时机、跨宿主恢复组合及统计 95% 可靠性均未建立。共享文件系统不鉴权，引用命中不证明语义成立，字段齐全不证明目标充分。
5. **评测范围**：57 个 eval 场景是维护中的定义，未全部进行模型运行。小样本对照只支持实际观察到的结果；入口变短不能直接当成成本、速度或成功率提升。
